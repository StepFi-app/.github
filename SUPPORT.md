# Getting Support

Thanks for using StepFi. Here is the fastest way to get the help you need.

## Questions & discussion

- **How-to / usage questions** — open a [Discussion](https://github.com/orgs/StepFi-app/discussions) or check the repository's `docs/`.
- **Documentation** — see [StepFi-Docs](https://github.com/StepFi-app/StepFi-Docs).

## Found a bug?

Open a bug report in the affected repository using the **🐛 Bug report** issue form. Include reproduction steps, environment, and severity.

## Have a security concern?

**Do not open a public issue.** Follow our [Security Policy](./SECURITY.md) and report privately.

## Contributing

Read [CONTRIBUTING.md](./CONTRIBUTING.md) before opening a pull request. Each repository may add its own contributing notes and a required pull request template — follow those exactly.
